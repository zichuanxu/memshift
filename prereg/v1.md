## 1. 测试集

- 世界：种子 1000–1019，N = 20。开发集（0–9）与校准集（900–909）与测试集不相交。
- N 的来源：按 v0 §6 的规则，N 取"使主对比 95% 区间宽度 ≤ 0.10 所需的世界数"，宽度按 1/√n 由开发集 10 个世界外推。所需世界数最大为 18（孤儿分支的 B 效应，宽度 0.132），其余主对比 ≤ 11，取 20。计划 §4.6 的起点 40 按同一规则下调；阶段 2 预算为 24 GPU·小时，按阶段 1 实测单价，20 个世界的 E1、E2、E3 约需 11 GPU·小时。
- 生成：本文件提交之后，由各实验按种子确定性生成（seed → 世界字节相同）。世界 SHA256、代码提交与模型 revision 记入各运行的 manifest。
- 噪声地板：每个测试世界做第二次摄入（同一写入模型，采样种子不同），与阶段 1 相同。
- 阶段 3 的世界从测试集取：E5 从 1000 起，个数由实测原生 t_i 按 §9 规则 4 定；E6 取全部 20 个；E7 与同步语义扩展取 1000–1004。

## 2. 设计修订（阶段 1 暴露，均已在 decisions.md 记录）

1. 范围粒度的第二档改为"写入模型引文所在簇"（cited）。读集簇（cluster）不进测试集。两个 D 臂都用写入模型的原始引文取簇，不用 D=1 兜底后的引用。
2. E1 探针：分叉前问全部 48 项。分叉后用判别探针：全部改变项，加上每个（世界, 分支, k）内按种子等量抽样的未变项。检测度量用全部项的 gold 与项历史，不受抽样影响。
3. E1 格：D ∈ {0,1} × {B=0, B=1 源纪元, B=1 引文簇}。JSON 臂取 D=1、B=1 源纪元。基线为零系统、RAG 与 oracle。分支为 S_src（主）、S_def、孤儿（依赖对象被删除，没有新证据）。
4. B=0 只追加：增量里没有新的范围内记录时，不调用写入模型。
5. D=1 兜底生成的 s_k 对定义项注明所用的定义版本及其陈述。
6. E4 事件抽样分层：先取系列、预约、设置类变化，再用一次性会议补足。

## 3. 否证阈值定稿（§2.4）

1. **路径 1（B 效应不足）**。B 效应 = Update(B=1 源纪元) − Update(B=0)，D 两档合并，在 S_src 上判定。点估计 ≤ +0.02 即触发。S_def 与孤儿分支的 B 效应照报，但不参与判定。
2. **路径 2（D 混入检测）**。D 对漏失效的效应 = MissedInvalidation(D=0, B=1) − MissedInvalidation(D=1, B=1)。在源纪元与引文簇两档粒度、S_src / S_def / 孤儿三个分支上分别计算。任一处 |点估计| ≥ 2 pp 且 95% 区间不含 0 即触发（v0 暂定的 2 pp 定稿）。阶段 1 在全部六处都精确为 0。触发后按 §5.2、§5.3 查边车泄漏，修复后重跑 E1；修不好则降级。
3. **路径 3（量化预测失败）**。对 D=0、B=1（源纪元）项做 logistic 回归：逐项存活 ~ 该项类型在校准集上的新旧写入一致率。主判定把三档（平级、升级、降级）的项合并，按世界做 bootstrap；斜率的 90% 下界 ≤ 0 或 AUROC < 0.60 即触发。三档各自的斜率与 AUROC 分别报告；若合并判定不触发、但某一档的斜率点估计 ≤ 0，量化主张加注"不适用于该档"。

## 4. 对比清单（固定；清单外的一律标为探索性）

在 v0 §5 的基础上做以下改动：

- **E1**（S_src、S_def、孤儿三个分支）：
  - B=1 对 B=0（D 固定、两档粒度）：检出率与 Update。
  - D=1 对 D=0（B=1 固定、两档粒度）：漏失效、误失效，以及 RepairCorrectness 的行为版与机械版。
  - 两档粒度之间：误失效与漏失效。
  - JSON 臂对 s_k 臂：干预前 ContractValid。
  - **新增（次要，方向已预测）**：B × D 交互 = [B 效应 | D=1] − [B 效应 | D=0]，看 Update，在 S_src 与 S_def 上各报一次。预测交互 > 0，即检测只有在修复可靠时才转化为行为收益。阶段 1（源纪元）：S_def 上 +30.3 pp [26.0, 34.5]（D=1 时 B 效应 +31.0 pp，D=0 时 +0.7 pp）；S_src 上 +10.8 pp [7.2, 14.6]。
  - **新增**：孤儿分支上的 B 效应（D 两档合并）。
- **E2**（测试世界 1000–1019，校准世界 900–909；平级、升级、降级三档）：
  - T1（§5）。
  - D=0 的校准斜率与 AUROC（路径 3）。
  - D=1 存活对检查器通过率。
  - B=0 的存活单独报告，不计入 T1：B=0 不把 θ_w 纳入键，换写入模型后不重派生，存活 ≈ 1 是"未更新"，不是"等效"。
- **E3**（测试世界）：零系统、HoldMem(1,1)、RAG、oracle 四个系统，地平线 1、3、12 个月。看静态 ContractValid、S_src 与 S_def 之后的 Update / Stability（取自 E1）以及五项成本。据此判定 T3（ε = 3 pp，对 oracle）与 T4（c = 0.5）。
- **E6**（阶段 3）：T2（§5）。另报一个不带派生扩展的导出臂，预测它的检测退化为 B=0。
- **E4 扩展**（阶段 3）：在官方同步语义下把 B 的交互扩到全部六类源。格子：{理想, 官方 L = 5 分钟} × B ∈ {0,1}（D=1）× {HoldMem, 零系统}，用判别探针。日历一源上交互的复现是主结果；其余五类源是描述性结果。

## 5. 等效边界（TOST，α = 0.05，即 90% 世界 bootstrap 区间落在 ±边界之内）

两条边界都取计划 §4.6 已固定的实际容差 ε = 3 pp，与 T3、门 A0 的零系统判据一致。边界不是从阶段 1 的 T1 估计反推出来的。

- **T1（换写入模型等效）**：对每一档，令 Δ = Retention(该档, HoldMem(1,1) 源纪元) − 1。"不换"时 store 不被触动，carryover 按构造等于 1。判据是 Δ 的 90% 区间落在 (−3, +3) pp 之内。由于 Retention ≤ 1，上界一侧自动满足，这条实际上是非劣检验。同一批世界的噪声地板（第二次摄入）一并报告，说明差距中有多少来自采样层面的波动。T1 按档分别判定；HoldMem 在某档"满足 T1"只对该档成立。
  - 阶段 1 平级档（10 个世界）：Δ = −2.2 pp，90% 区间 [−3.2, −1.2]，下界越过 −3 pp，按本判据在开发集上**不满足** T1。按 1/√n 外推到 20 个世界，下界约为 −2.9 pp，因此 T1 在测试集上是否成立确实悬而未决。升级档与降级档没有阶段 1 数据。
- **T2（离开等效）**：同一世界、分支与探针上配对，要求下面三个差的 90% 区间都落在 (−3, +3) pp 之内：
  - ContractValid(导入, 带扩展) − ContractValid(原实现)，t0 处；
  - 同一差值，S_src、S_def 之后（k 合并）；
  - MissedInvalidation(导入, 带扩展) − MissedInvalidation(原实现)。
  ExportFidelity = ContractValid(导入) / ContractValid(原实现) 作为描述量同时报告。
